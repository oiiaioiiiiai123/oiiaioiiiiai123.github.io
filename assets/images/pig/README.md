# 用户原图与局部表情

`pig-original.png` 为不可变的用户原图：1216×1181 RGBA、Display P3、透明背景，SHA-256 `ad85b66a4d2d86026caef1f26437980bd273af8e2ff69a2fa3d0c98942884935`。没有覆盖、重绘或修改它。

首页和 Pig's Room 复用 `_includes/pig.html`：原图与透明 Canvas 位于同一个 `.pig-portrait` 内，使用原始比例缩小显示，一起进行轻跳、呼吸等动作。favicon 和 404 仍直接使用原图。alpha 边界 (52,132)–(1169,1118) 的居中校正保留。

Canvas 只可修改三个原图坐标区域：左眼 [164,488,270,607)、右眼 [449,546,551,663)、嘴巴 [322,814,390,863)。其他像素保持透明，身体、鼻子、耳朵、四肢、尾巴、粉色花纹始终来自原图。

眼睛先用相同行完整皮肤像素的插值修复原黑眼，再绘制新眼睛。颜色直接取自浏览器解码的原图，避免 Display P3 与 CSS 颜色不一致。眨眼用原图眼睛裁片沿高度闭合，最后变为柔和闭眼曲线，再恢复；开心是局部笑眼与小微笑；投喂是鼻子下的小开口和三次咀嚼；睡眠是真闭眼；彩蛋是笑眼与小微笑。Idle 清空 Canvas，完全显示原图。没有完整尺寸派生帧或新的角色 SVG。

嘴部接触点为 (355,836)。投喂使用实际图片矩形映射相同坐标，拖拽从释放位置继续缩小。角色为 normalPig / doctorPig；动作状态统一为 idle / blinking / happy / feeding / sleeping / special / transforming；动作打断会取消旧的帧与计时器。减少动态效果时取消自动眨眼与身体/胡萝卜运动，仍显示静态的语义表情。计数只存在 sessionStorage。

`archive/` 保留之前的小图与旧 SVG，正式组件没有加载它们。原图、CSS、JS 引用带构建版本参数。浏览器验收输出位于工作空间 `docs/pig-preview/`，不是公开素材。

## 医生猪

主体和闭眼参考逐字节保存在 `doctor/`。主体为用户提供的 695×859 透明 PNG，不重绘、不抠图、不锐化或改色；原图自带的柔和边缘保留。`doctor-original.png` 为正式默认形象，`doctor-closed-reference.png` 的衣服和手持物与主体不同，因此仅作闭眼参考，不在网页整帧交替显示。详见 `doctor/README.md`。

首页仅显示普通猪；Pig's Room 启用同一组件的 doctor 参数。医生原图与局部 Canvas 一起按695:859显示，透明边距单独校正。听诊器预加载下一角色、280ms交叉淡入，结束移除临时旧图；快速点击、投喂期间禁止并发切换，动作计时器随角色切换重置，计数保留。减少动态效果时直接切换。
